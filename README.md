
# PackMC

**PackMC** is a modern Minecraft Pack Editor that lets you create **Resource Packs** directly in your browser. It’s built with a clean UI and a modern framework for fast, efficient workflows.

---

## Features

- Create packs online — free and easy  
- View unedited textures and sort them however you like  
- Export your pack in the correct format instantly  

---

## How to Use

Visit:  
--> https://packmc.vercel.app

1. Press Get Started to go the Main App
2. Create a new Pack with the Button in the top right
3. Choose a texture to edit. filter for types on the left and search, sort and filter for edited and unedited on the top of the texture view.
4. Choose a texture to edit, hover over it, press edit
5. Use the editor to edit it, you can change the color and use differt tools
6. If you're finished with editing press Save File in the top right
7. When u edited all textures you wanted to edit press export in the texture Browser. (for now the name discription and version (1.21.11) is fixed you can not change it).
8. Put it into the minecraft resource packs folder and activate it!
